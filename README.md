# Ollama Test Hallucination

Скрипт проверяет ответ LLM-модели на соответствие заранее заданному правильному ответу.

Скрипт принимает два параметра:
1. вопрос;
2. правильный ответ.

После этого он:
- отправляет вопрос в локальную модель через Ollama;
- получает ответ модели;
- сравнивает его с правильным ответом;
- выводит `Правильный ответ`, если ответ соответствует ожидаемому;
- выводит `Галлюцинация`, если ответ не соответствует ожидаемому.

## Требования

- Python 3
- Ollama
- модель `llama3.2:latest`
